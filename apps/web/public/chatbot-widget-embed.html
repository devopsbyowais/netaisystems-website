Chatbot Widget Demo

This page demonstrates the standalone vanilla JavaScript chatbot widget.

How it works

Look at the bottom right corner of your screen. You should see a floating chat button. Click it to open the chat interface and interact with the API.

The widget is completely self-contained. It injects its own HTML and CSS, and handles all API communication internally.

Embed Code

To add this widget to any website, simply include the following script tag just before the closing </body> tag:

<script src="https://yourdomain.com/chatbot-widget.js"></script>
